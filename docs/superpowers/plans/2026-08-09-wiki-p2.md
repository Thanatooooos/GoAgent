# Wiki P2 实施计划：图谱检索源

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让聊天检索命中 wiki 页面及其图邻居：新增 `wiki_page` 检索通道（关键词 + 1 跳图邻居），经 RRF 融合进 rag 引擎。

**Architecture:** `WikiPageRepository.Search`/`ListByIDs`（Postgres ILIKE + 批量取）→ `wikiretrieval.Retriever`（命中页 + 图邻居 → `convention.RetrievedChunk`）→ `rag/core/retrieve.wikiPageChannel`（`SearchChannel`）+ `Engine.SetWikiRetriever` → bootstrap 注入。

**Tech Stack:** Go 1.25 标准库 + GORM。

**参考设计:** `docs/superpowers/specs/2026-08-09-wiki-p2-design.md`
