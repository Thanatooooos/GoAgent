## 1. 开工与阶段顺序

工作区已有大量未提交变化，先记录将修改文件的既有状态，逐段增量修改。Go 测试使用工作区 GOCACHE，集成测试使用专用隔离库；不默认使用生产 `ragent` 库。

开发阶段按 karpathy-guidelines 控制范围；阶段完成与最终交付按 spec-delivery-audit 检查 module、integration、delivery。以下复选框只有在实际入口、持久化、用户可见结果和相关验证完成后才勾选。

## 4. 阶段 3：AI 成果与进展建议

- [x] 定义 typed Work 输入意图与允许动作，覆盖普通讨论、明确创建/修改、对象歧义；工具范围只由真实用户输入确定。
- [x] 保存绑定 user message/target/base revision 的 action，聚焦对象或资料中的指令不能独自授予写入权限。

- [x] 补 tool_call_id 与 Work 操作关联；相同 turn/action 写入唯一，输入改变或版本冲突时不重试覆盖。

## 8. 核心验收矩阵

| 承诺 | 模块/数据库证明 | 正式入口及用户可见证明 |
| --- | --- | --- |
| 创建并持续使用主题 | 拥有者及关联一致 | Work 创建后可立即聊天，刷新/重启后可继续 |
| 事项与主题隔离 | scoped query/turn snapshot | 两主题与同主题两事项的实际对话不误用资料/决定 |
| 成果独立与可修订 | CAS、不可变版本、恢复事务 | AI/手动修改均可查看版本，冲突保留输入 |
| 建议确认后生效 | proposal apply 幂等及 revision 门槛 | 忽略/未确认不变；编辑后确认准确更新 |
| 历史与依据可追溯 | 持久化消息、版本 refs、scope | 新对话可接续，引用打开正确消息/版本 |
| 资料共享与附件范围 | 私有容器、source 关联、query filter | 本次附件提升前后跨对话可用范围确实改变 |
| 中断下仍有可信结果 | input/operation 幂等、journal 对账 | 工具写入成功但回复失败，刷新后仍能看到真实结果 |
| 现有能力保持可用 | 有针对性的回归用例 | 普通聊天/定时任务/KB 从原入口正常运行 |

## 9. 验证命令与环境要求

以下包及正式入口已创建。最终 Go 全量、实际专用库及前端 build 验证已通过，详见交付报告：

```powershell
$env:GOCACHE='D:\goagent\tmp\codex-gocache'
go test -p 1 ./internal/app/work/... ./internal/adapter/http/work/... ./internal/adapter/repository/postgres/work/... ./internal/bootstrap/work/... -count=1
go test ./internal/app/runtime/... ./internal/adapter/runtime/... ./internal/app/rag/service/conversation/... ./internal/adapter/http/rag/... ./internal/bootstrap/rag/... -count=1
go test ./cmd/... ./internal/... -count=1
```

集成测试采用新专用 `WORK_TEST_DSN` 并在正式仓储用例中校验隔离库身份，迁移自行初始化。未设置 DSN 的跳过不算数据库验收；不输出 `.env`、DSN 密码或模型密钥。

前端按项目当前 bundled Node 与 npm-cli.js 执行 build，应用类型检查指向 `frontend/tsconfig.app.json`。既存全量类型错误分别记录，不能因 Work 文件无错误称全量通过。Playwright 使用当前已安装运行时，未经需要不安装/升级依赖。

本轮已执行实现验证。同机不同测试包共享数据库时，现有 ID 生成器可能碰撞，数据库组合套件使用 `-p 1`；未设置 DSN 的跳过不计数据库通过。前端全量类型检查仍有既存错误。阶段 6 原功能回归已补齐知识库选择/上传分块/实际检索、画像观察仓储排除和普通领取、任务汇报 UI。画像基座用真实 DB + 服务测试，汇报展示用合成 outcome + 真实事务，不把它们称为这次真实模型形成画像或执行任务的证明。

预览误连接原有库的影响和已完成防护见 [事件记录](../reports/2026-10-01-work-preview-config-incident.md)，原有数据未自动回滚。阶段勾选表示列出的行为已实现且有证据，不表示获准部署或完成原有数据处置。
